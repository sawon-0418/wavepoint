# 물결포인트

## 어종별 조과 랭킹 배포

1. Supabase SQL Editor에서 `supabase_schema.sql`의 `-- 어종별 조과 랭킹:` 주석부터 마지막 `commit;`까지 실행합니다. 새 프로젝트는 파일 전체를 실행합니다.
2. 해당 SQL이 성공한 다음 코드 변경을 커밋·푸시하고 Render 배포 완료를 확인합니다.
3. 메인의 `어종별 조과 랭킹`에서 기존 어종과 TOP 5가 표시되는지 확인합니다.
4. 새 어종으로 조과를 등록하면 어종 선택 목록에 추가됩니다. 같은 이름은 띄어쓰기와 대소문자를 무시해 하나로 연결됩니다. 별칭·오타는 자동 병합하지 않습니다.
5. 같은 계정의 같은 어종은 최고 길이 한 건으로 순위를 계산합니다. 동률은 공동 순위(1, 1, 3), 화면은 최대 5명을 표시합니다. 내 순위는 전체 기록으로 계산합니다.
6. 길이 수정, 어종 변경, 숨김·복구, 삭제 후 해당 어종 랭킹을 확인합니다. 숨겨진 포인트의 조과도 제외됩니다.

`fish_species`는 어종 목록, `posts.species_id`는 어종 연결입니다. DB 트리거가 조과 저장과 어종 생성을 같은 트랜잭션에서 처리합니다. 랭킹은 DB 뷰와 서버 전용 RPC에서 조회 시 계산합니다. 기존 전체 조과 랭킹은 유지됩니다.

로컬 확인: `python3 -m unittest test_species_rankings -v`. 랭킹 SELECT의 윈도 함수는 SQLite로 검증하며, PostgreSQL 트리거·RPC·권한은 실제 Supabase 적용 후 확인해야 합니다.
